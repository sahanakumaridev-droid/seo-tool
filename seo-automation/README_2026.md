## 📞 Support

### Common Issues

**Q: Backend not starting?**
A: Check that all dependencies are installed: `pip install -r requirements.txt`

**Q: Frontend not loading?**
A: Ensure Node.js is installed and run: `npm install && npm run dev`

**Q: Metrics not updating?**
A: Check browser console for errors. Ensure backend is running.

**Q: Colors not showing?**
A: Ensure Tailwind CSS is properly configured in vite.config.js
