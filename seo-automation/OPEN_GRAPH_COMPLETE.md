<meta property="og:description" content="Looking for the best plumbing in San Diego? Our proven team delivers...">

## 🐛 Troubleshooting

### Issue: Image not showing
**Solution:**
- Check image URL is publicly accessible
- Use absolute URL (https://...)
- Image must be at least 200x200px
- Test with Facebook Debugger

### Issue: Old content showing
**Solution:**
- Facebook caches for 7 days
- Use "Scrape Again" in Facebook Debugger
- Wait 24 hours for other platforms

### Issue: Tags not working
**Solution:**
- Check tags are in `<head>` section
- Validate HTML syntax
- Check for typos in property names
- Use validators to debug
